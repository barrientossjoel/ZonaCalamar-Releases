# Zona Calamar (Platense) — Releases

Este repo **no tiene código fuente navegable**: es solo un contenedor de las
[Releases](../../releases) con el `.apk` para instalar **Zona Calamar**, la app de
beneficios para socios de Platense.

La app habla directo con el servidor central publicado — no necesita backend local ni
instalar dependencias de desarrollo.

## Descargas (última release)

| Archivo | Para qué |
|---|---|
| `ZonaCalamar.apk` | Instalar en un celular/tablet **Android**. |

## Instalación — Android

1. Descargar `ZonaCalamar.apk` desde la [última release](../../releases/latest) al
   celular (por WhatsApp, Drive, mail o descarga directa desde GitHub).
2. Abrir el archivo descargado. Aceptar "instalar apps de origen desconocido" si Android
   lo pide.
3. Abrir la app "Zona Calamar" ya instalada.

## Código fuente

El código completo (app + backend + panel admin) vive en un repositorio privado.
